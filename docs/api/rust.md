# Rust API

The engine is a Rust library; its API reference is generated by `cargo doc` and published with these docs:

<p><strong><a href="../rust/physim/index.html">Open the Rust API reference</a></strong></p>

The main entry points: `World` (state, forces, integrator, run loops, events, checkpoints), the `Force` and
`Integrator` traits, `RigidSystem`, and the modules `forces`, `integrators`, `constraints`, `collisions`, `chaos`,
`adaptive`, `rigid`, `rng` (counter-based random numbers) and `nuclear` (the nuclear planner's event generator). Building locally:

```bash
cargo doc --no-deps --open
```
